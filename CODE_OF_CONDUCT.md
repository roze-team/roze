# Code of Conduct

Roze follows the Contributor Covenant Code of Conduct.

Until the project publishes a full community governance process, contributors
are expected to:

- Be respectful and direct.
- Keep technical disagreements focused on evidence, tradeoffs, and project
  goals.
- Avoid harassment, personal attacks, or discriminatory language.
- Respect maintainers' decisions about scope, release readiness, and security
  handling.

Maintainers may remove comments, issues, pull requests, or contributors that
violate these expectations.
